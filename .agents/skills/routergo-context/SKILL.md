# RouterGo Context

Use this skill at the start of any RouterGo task.

1. Read `AGENTS.md`, constitution, active feature spec/plan/tasks.
2. Inspect the real filesystem/code before planning edits.
3. Classify ownership: identity, economy/wallet, ai-routing/API, skills, CMS, ads, challenges/exercise, battle, treasure, risk/analytics, or UI.
4. Load the matching RouterGo specialist skill.
5. State affected invariants, external dependencies, tests, migrations, and runtime-manifest impact before implementation.
6. Do not let older `.agents/plans/*` override Rev.7.

If the request crosses contexts, define one integration owner and separate parallel tasks with non-overlapping file ownership.
